# 倉庫盲盒競標 · Warehouse Auction

一款以神秘倉庫為主題的單人瀏覽器競標遊戲。觀察有限情報、估算藏品價值，與三名電腦競標者爭奪倉庫；得標後開箱，決定要出售藏品，還是放進展示館持續賺取收益。

**[開始遊玩](https://mihusan19-cloud.github.io/warehouse-auction/)** · 無需帳號、後端或 API Key

## 遊戲特色

- 每局隨機產生倉庫、藏品與特殊事件；三種會場有不同的入場條件與物品範圍。
- 與三名電腦競標者進行最多六回合的密封出價。出價前只能看到「已完成喊價」，待全員完成後才逐一公布結果。
- 根據倉庫格子、公開線索、鑑定助理與商店儀器推測價值。未公布情報的物品不會直接顯示身分或品質。
- 收集 250 種物品，使用圖鑑搜尋、篩選與排序；藏品可批量出售，或放進展示館。
- 展示館最多陳列 25 件藏品；有展品時才累積收益與展示時數，空館則暫停，最多累積 168 小時後需手動領取。
- 支援桌機、手機和平板；以瀏覽器 LocalStorage 保存進度，並可匯出、匯入 JSON 存檔。

## 玩法概要

新玩家以 **$3,000,000** 開始。每局先選會場與一名助理，也可以用遊戲資金購買鑑定儀器。倉庫開啟後，遊戲會抽選一項倉庫事件。

每回合有 60 秒，每位競標者只能出價一次；輸入 `0` 表示放棄該回合。第 1、2、3、5 回合會提供公開情報，第 4 回合則留給玩家整理資訊。倉庫中的情報均為真實資訊。

| 回合 | 提前結標條件 |
| --- | --- |
| 第 1 回合 | 最高價 **大於**第二高價的 2 倍 |
| 第 2 回合 | 最高價 **大於**第二高價的 1.7 倍 |
| 第 3 回合 | 最高價 **大於**第二高價的 1.5 倍 |
| 第 4 回合 | 最高價 **大於**第二高價的 1.3 倍 |
| 第 5 回合 | 最高價得標；最高價平手則進入第 6 回合 |

提前結標須有大於 `0` 的第二高價。第 6 回合出價不得低於自己第 5 回合的出價；若仍平手，倉庫流標。結算會顯示最高喊價、倉庫實際價值及盈虧。若得標價高於實際價值，每位未得標者各獲得虧損額 **10%** 的回饋；得標者不會因此被額外扣款。

助理與儀器提供的情報不同，例如總佔格數、物品品質、實際尺寸、單品身分或總價值範圍。儀器需先在鑑定商店購買，且玩家鎖定本回合出價後不可再使用。會場、助理、儀器與事件的詳細說明可在遊戲內查看。

## 在本機執行

本專案是純靜態網站。**遊戲入口是 `index.html`，不需要執行任何 `.py` 遊戲檔。** 由於遊戲會載入 JSON 和 JavaScript 模組，請透過本機 HTTP 伺服器開啟，不要直接以 `file://` 開啟檔案。

在 Windows PowerShell 中進入專案資料夾後執行：

```powershell
cd C:\Users\User\Desktop\warehouse-auction
py -m http.server 8000 --bind 127.0.0.1
```

接著在瀏覽器開啟 **http://127.0.0.1:8000/**。若電腦沒有 Python，也可以使用編輯器的 Live Server 等靜態網站伺服器。上述 Python 指令只用於本機預覽，部署到 GitHub Pages 時不需要 Python。

## 部署到 GitHub Pages

1. 將專案檔案上傳至 GitHub 儲存庫，確認 `index.html` 位於儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選擇要發布的分支及 **`/(root)`** 資料夾，儲存後等待部署。

網站只使用 HTML、CSS、JavaScript 與 JSON；不需要建置流程、後端伺服器或 API Key。若更新後仍看到舊畫面，請先強制重新整理，並等待瀏覽器的離線快取更新。

## 存檔與資料

玩家名稱、資金、收藏、展示館、成就與設定保存在目前瀏覽器的 **LocalStorage**。不同瀏覽器、裝置或網站網址不會自動共用存檔；清除網站資料也可能刪除進度。換裝置或清除資料前，請先到遊戲「設定」匯出 JSON 存檔，之後再匯入。

主要可調整資料放在 `data/`：

| 檔案 | 內容 |
| --- | --- |
| `items.json`、`qualities.json` | 物品系列、名稱、價值、大小與品質資料 |
| `warehouseTemplates.json` | 倉庫格子與生成設定 |
| `auctionMeta.json` | 會場、鑑定助理與儀器 |
| `auctionConditions.json` | 隨機事件及各會場權重 |
| `ai.json` | 電腦競標者資料與對話 |
| `showroomConfig.json` | 展示上限與收益設定 |
| `achievements.json` | 成就條件 |

`js/` 存放遊戲邏輯，`css/` 存放介面樣式，`sw.js` 與 `manifest.json` 提供 PWA／離線快取所需檔案。

## 測試

若已安裝 Node.js，可在專案根目錄執行：

```powershell
node --test tests/*.test.mjs
```

Node.js **只用於執行自動測試**，不是玩家遊玩或 GitHub Pages 部署的必要條件。
